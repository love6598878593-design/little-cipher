# Little Cipher

Little Cipher is a premium family-learning SaaS concept for children ages 6–11. The public site presents the membership, pricing, interactive riddle demo, and local trial prototype.

## Memberships

- Explorer — $19/month
- Family Salon — $39/month
- Founding Family — $290/year

## Local preview

Open `index.html` directly or serve this directory with any static HTTP server.

## Status

This repository contains the public frontend prototype. Production authentication, recurring billing, member profiles, and the private library require a separate application backend.
